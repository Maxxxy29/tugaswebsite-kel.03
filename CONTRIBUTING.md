
# Panduan Kontribusi

Terima kasih telah berkontribusi pada **tugaswebsite-kel.03** 🎉  
Berikut panduan sederhana untuk anggota kelompok:

## 🧭 Alur Kerja Kolaborasi
1. **Fork** atau **Clone** repo ke komputer/HP masing-masing.  
2. Buat **branch** baru sesuai bagian tugasmu. Contoh:
   ```bash
   git checkout -b fitur-about
   ```
3. Lakukan perubahan pada file sesuai bagianmu.  
4. Commit dengan pesan yang jelas:
   ```bash
   git add .
   git commit -m "Tambah halaman about"
   ```
5. Push ke branch kamu dan buat **Pull Request (PR)** ke branch `main`.  
6. Minta review minimal 1 anggota sebelum merge.

## 👥 Pembagian Tugas
- Ketua: Struktur & `index.html`
- Anggota 1: Profil (`about.html`)
- Anggota 2: Kegiatan (`kegiatan.html`)
- Anggota 3: Kontak (`contact.html`)
- Anggota 4: Desain (`style.css`) dan JS (`script.js`)

## 📌 Tips
- Selalu `git pull` dari `main` sebelum memulai kerja.
- Jangan edit file bagian anggota lain tanpa diskusi.
- Periksa tampilan website sebelum PR.

Happy coding 💻✨
