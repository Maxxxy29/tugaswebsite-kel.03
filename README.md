# tugaswebsite-kel.03

Website sederhana untuk tugas kolaborasi kelompok (5 orang).

Isi:
- index.html
- about.html
- kegiatan.html
- contact.html
- style.css
- script.js

Cara pakai:
1. Extract ZIP.
2. Buka `index.html` di browser untuk melihat website.
3. Upload ke repository GitHub dan gunakan branch/pull request untuk kolaborasi.
